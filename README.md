# Headlines - build your APK (no coding)

1. Create a free account at https://github.com and make a new repository.
2. Upload ALL files from this folder (App.js, app.json, eas.json, package.json, babel.config.js).
3. Create a free account at https://expo.dev and open "Projects" > "Create project",
   then connect your GitHub repository.
4. In the project, go to Builds > "Create build": platform Android, profile "preview".
5. After a few minutes, open the build page on your phone and tap Install / download the .apk.
   Allow "install unknown apps" when Android asks.
